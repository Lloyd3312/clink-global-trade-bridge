# Clink Global Trade Bridge

Clink Global Trade Bridge is a responsive digital platform connecting individuals and businesses with sourcing, trade, investment, and education-support opportunities involving Türkiye.

## Services

- International product sourcing
- Export and supplier connections
- Fashion and textile sourcing
- Steel and industrial-product sourcing
- Turkish real-estate guidance
- Study-in-Türkiye university consultation
- University application support
- Scholarship and affordable-school searches
- Tuition-deposit guidance
- Student-visa preparation support

## Technology Stack

- React
- TypeScript
- Vite
- Tailwind CSS
- shadcn/ui
- Docker
- GitHub Actions
- Kubernetes
- Minikube

## DevOps Implementation

The application is containerised with Docker. GitHub Actions is used for continuous integration to install dependencies, build the application, create versioned Docker images, and push the images to a container registry. Kubernetes manifests are included for deploying the application to a local Minikube cluster.

## Local Development

```bash
npm install
npm run dev
```
